# Day 18 - 30 Days Python Challenge 🐍

## What I Learned Today
- Utility Commands
- The Walrus Operator (`:=`)

## Programs Written

### 1. Event Ticket Booking System
A program that manages ticket bookings for an event using the walrus operator
to take customer input and check it in the same line. Also calculates GST and
tracks total revenue, tickets sold, and the highest-paying customer.

### 2.Assistant
A command-line assistant built using `argparse` that opens a website in the
browser based on a given command, and uses text-to-speech to confirm the
action out loud.

## Concepts Covered
- The Walrus Operator (`:=`)
- Dictionary-based record storage
- The `argparse` module for building CLI tools
- `webbrowser` module for opening websites
- Text-to-Speech using `os.system()`
