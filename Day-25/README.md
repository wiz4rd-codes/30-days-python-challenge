# Day 25 - 30 Days Python Challenge 🐍

## What I Did Today
Instead of learning new concepts, today was about combining everything learned
so far into two solid, practical projects — solidifying OOP fundamentals.

## Programs Written

### 1. Expense Tracker
A program that tracks multiple expenses, calculates the total and average
spend, and finds the highest expense using `max()` with a `lambda` key.

### 2. File Vault System
A complete OOP project with `File` and `Vault` classes — supports adding,
removing, searching, listing, and finding the largest file, while tracking
used and free storage capacity.

## Concepts Reinforced
- Classes and objects working together
- `max()` with a custom `lambda` key
- List management (add, remove, search)
- Menu-driven program design with a `while` loop
