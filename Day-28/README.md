# Day 28 - 30 Days Python Challenge 🐍

## What I Did Today
Built two practical daily-use tools.

## Programs Written

### 1. Password Strength Checker
A program that checks a password for uppercase, lowercase, digits, and
special characters, and rates it as Strong, Medium, or Weak.

### 2. Study Timer (Pomodoro-style)
A program that automatically runs study and break sessions on a loop using
`time.sleep()`, tracking total sessions and total study time until the user
chooses to stop (using the walrus operator for input handling).

## Concepts Covered
- String methods (`isupper()`, `islower()`, `isdigit()`, `string.punctuation`)
- Conditional scoring logic
- `time.sleep()` for scheduled/timed loops
- The walrus operator (`:=`) for inline input checking
