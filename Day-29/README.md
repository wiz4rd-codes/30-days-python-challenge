## 😂 Program 1 — Joke Generator

A simple API-based joke generator using the `requests` module.

* Displays the setup first

* JSON response
* Dictionary data

## 🔎 Program 2 — File Search Tool

A simple utility that searches for files inside a selected folder based on a filename or keyword.

### Features

* Takes a folder path from the user
* Takes a filename or keyword to search
* Performs case-insensitive matching
* Displays all matching files
* Shows the total number of files found

### Concepts Used

* `os` module
* `os.listdir()`
* Lists
* Loops
* String methods
* Case-insensitive searching
* `len()`

### Example

```text
Enter path of the folder : Downloads
Enter file name you want to search : resume

Found :
Resume.pdf
resume_final.docx
my_resume.pdf

Total Files Found : 3
```
