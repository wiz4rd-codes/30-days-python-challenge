# Day 22 - 30 Days Python Challenge 🐍

## What I Learned Today
- Regular Expressions (`re` module)
- Asynchronous Programming (`asyncio`)

## Programs Written

### 1. Restaurant Kitchen System
A program that simulates a restaurant kitchen using `asyncio` — multiple
orders are prepared concurrently using `asyncio.gather()`, so the total wait
time equals only the longest order's prep time instead of the sum of all orders.

### 2. Email & Phone Number Extractor
A program that uses Regular Expressions (`re.findall()`) to extract all email
addresses and 10-digit phone numbers from a text file.

## Concepts Covered
- Regular Expressions (`re.findall()`, pattern matching)
- Asynchronous programming with `async`/`await`
- `asyncio.gather()` for concurrent task execution
- File reading with `open()`
