# Day 26 - 30 Days Python Challenge 🐍

## What I Did Today
Worked with real-world APIs to build two practical tools.

## Programs Written

### 1. FilmRadar
A program that fetches complete details of any movie (rating, plot, cast,
director, box office, etc.) using the OMDb API.

### 2. GitScan
A program that fetches a GitHub user's public profile data — bio, followers,
public repos, location, company, and more — using the GitHub API.

## Concepts Covered
- Making API calls with the `requests` module
- Parsing JSON responses
- Handling API errors and invalid inputs (`response.status_code`, `data.get()`)
- Working with two different real-world public APIs
