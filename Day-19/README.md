# Day 19 - 30 Days Python Challenge 🐍

## What I Learned Today
- The `shutil` Module
- The `requests` Module

## Programs Written

### 1. Folder Organizer
A program that automatically organizes messy files inside a folder into
separate categorized folders (images, pdfs, videos, python_files, text_files,
others) using the `shutil` module, based on file extensions.

### 2. Weather Checker
A program that fetches live weather data (temperature, humidity, chance of
rain, wind speed) for any city using the `requests` module to call a public
weather API.

## Concepts Covered
- File organization using `shutil.move()`
- Working with directories using `os.chdir()`, `os.listdir()`, `os.makedirs()`
- Making API calls with the `requests` module
- Parsing JSON responses
