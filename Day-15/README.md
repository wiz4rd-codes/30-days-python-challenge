# Day 15 - 30 Days Python Challenge 🐍

## What I Learned Today
- Single Inheritance (in detail)
- Multiple Inheritance (in detail)

## Programs Written

### 1. Animal & Cat System
A program demonstrating Single Inheritance — `Cat` inherits from `Animal`,
reuses the parent's data using `super()`, and overrides the `sound()` method
with its own behavior.

### 2. SmartPhone System
A program demonstrating Multiple Inheritance — `SmartPhone` inherits from
both `Camera` and `MusicPlayer`, combining data and methods from two parent
classes into a single object.

## Concepts Covered
- Single Inheritance
- Multiple Inheritance
- `super()` vs explicit `ParentClass.__init__(self, ...)` calls
- Method overriding
- Object list management with `enumerate()`
