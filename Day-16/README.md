# Day 16 - 30 Days Python Challenge 🐍

## What I Learned Today
- Multilevel Inheritance (in detail)
- Hierarchical Inheritance (in detail)
- Hybrid Inheritance (in detail)

## Programs Written

### 1. Premium EBook System
A program demonstrating Multilevel Inheritance — `PremiumEBook` inherits from
`EBook`, which inherits from `Book`, passing data down across three levels.

### 2. Fullstack Course System
A program demonstrating Hybrid Inheritance — `Programming` and `Design` both
inherit from `Course` (Hierarchical), and `Fullstack` inherits from both
`Programming` and `Design` (Multiple), combining all their data and methods.

## Concepts Covered
- Multilevel Inheritance
- Hierarchical Inheritance
- Hybrid Inheritance
- Explicit parent class method calls (`ParentClass.__init__(self, ...)`)
- Object list management with `enumerate()`
