# Day 21 - 30 Days Python Challenge 🐍

## What I Learned Today
- Practical use of the `requests` module (News API)
- Practical use of the `time` and `os` modules

## Programs Written

### 1. News Fetcher
A program that fetches live news headlines by category using the `requests`
module, calling a News API and filtering results from the past 7 days using
`datetime` and `timedelta`.

### 2. Water Reminder System
A background reminder program that alerts the user every 2 hours to drink
water using `time.sleep()`, and speaks the reminder out loud using
`os.system()`. Also tracks total glasses of water consumed.

## Concepts Covered
- Making API calls with the `requests` module
- Working with dates using `datetime` and `timedelta`
- Infinite loops with `time.sleep()` for scheduled reminders
- Text-to-Speech using `os.system()`
