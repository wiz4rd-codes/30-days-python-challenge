# Day 27 - 30 Days Python Challenge 🐍

## What I Did Today
Practical, real-world uses of decorators — going beyond theory into fun and
useful applications.

## Programs Written

### 1. Typewriter Effect
A decorator that makes any function's returned text print out letter-by-letter
with a delay, creating a movie-style typewriter effect.

### 2. Execution Timer
A decorator that measures and prints the exact execution time of any function
it wraps, tested on a prime number finder that checks numbers from 0 to 1000.

## Concepts Covered
- Decorators with `*args` and `**kwargs`
- `time.perf_counter()` for precise time measurement
- Character-by-character printing with `time.sleep()`
